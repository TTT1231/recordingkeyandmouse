# Repeat 项目文档

Repeat 是面向 Windows/Linux 的桌面键鼠录制、编辑与回放工具。用户连续操作一段时间后，可以查看时间线、修改必要参数，再复现这段操作。

| [功能需求](requirements.md)                             | 确认产品范围、界面行为、验收条件和仍需确定的问题                           |
| [技术方案与选型](decisions/0001-technical-selection.md) | 理解 Tauri + Rust 的职责划分、平台输入后端、定时回放、数据存储和验证顺序   |
| [实施计划](implementation-plan.md)                      | 按阶段开展原生验证、工程实现、编辑器接入和平台交付，核对任务依赖与验收条件 |
| [桌面交互原型](index.html)                              | 对照任务管理、预览、录制内容、时间线和帮助演示的交互                       |

## 维护约定

- 产品行为以功能需求为主要归属；技术方案引用需求编号，不另行修改产品范围。
- 阶段进度、完成清单、验证结果和剩余问题统一维护在实施计划；README 只提供介绍与阅读入口。
- 新的用户确认、交互变更或平台验证结论，应同步修改对应文档。
- 已确认需求、实现建议、原型行为和实测结果分开记录。没有完成原生验证的能力，不标记为已实现或已支持。
- 原型中的示例任务和练习表单是演示内容，不能作为已经实现系统监听、控件识别或屏幕录像的证据。
