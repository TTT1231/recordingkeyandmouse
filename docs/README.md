# Repeat 项目文档

更新日期：2026-10-26。

Repeat 是面向 Windows/Linux 的桌面键鼠录制、编辑与回放工具。用户连续操作一段时间后，可以查看时间线、修改必要参数，再复现这段操作。

## 当前阶段

当前已整理需求、交互原型、技术建议与分阶段实施计划，并建立了 Tauri 2 + Rust + React/TypeScript 工程脚手架（含 lint、类型检查、单元测试与 CI 配置）。尚未开始实现系统级录制。

实施计划已完成一轮范围审查：先做真实录放，再尽早接通编辑、保存与执行试用；历史版本、中断恢复及存储/绘制优化按明确需求或测量结果引入。已确认功能与验收场景全部保留。

检查当前仓库可确认：`docs/index.html` 是包含界面、脚本和资源的独立 HTML 原型，其中的录制仅限原型画布；仓库根的 Tauri/Rust 工程目前是官方脚手架加工程化配置，通过编译与静态检查，但尚未实现操作系统级监听、注入或任何原生性能验证，实施计划 M1 及之后任务均未开始。

Tauri + Rust 是用户已确认的技术方向。交付顺序已确认先 Windows（支持基线 Windows 10+ x64）、再 Linux X11（目标验证环境 Ubuntu 24.04 LTS、Xorg 会话），Wayland 单独验证；首版手动导入预览参考图，键盘先忠实录放按键，新增或编辑文本单独处理。2026-10-26 用户授权无人值守推进，全部未决事项已定稿：键盘不做布局/输入法专门适配，停止以工具内按钮为主、F8/F9 全局快捷键兜底，不设用户评定的性能门槛，无历史版本/回收站/导入导出，执行支持循环次数（用户填写、默认 10 次）；明细见[功能需求第 7 节](requirements.md)与[实施计划第 6 节](implementation-plan.md)。输入库、性能数值和存储实现仍属于技术建议或待验证事项，状态见技术选型文档。

## 维护约定

- 产品行为以功能需求为主要归属；技术方案引用需求编号，不另行修改产品范围。
- 新的用户确认、交互变更或平台验证结论，应同步修改对应文档。
- 已确认需求、实现建议、原型行为和实测结果分开记录。没有完成原生验证的能力，不标记为已实现或已支持。
- 原型中的示例任务和练习表单是演示内容，不能作为已经实现系统监听、控件识别或屏幕录像的证据。
