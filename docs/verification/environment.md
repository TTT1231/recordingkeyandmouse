## 显示器与 DPI

| 项目       | 值                                       |
| ---------- | ---------------------------------------- |
| 显示器数量 | 1（`\\.\DISPLAY1`，主屏）                |
| 物理分辨率 | 1920×1080（推算，见下方说明）            |
| 系统缩放   | 125%（AppliedDPI=120）                   |
| 虚拟桌面   | (0,0) 起，1536×864（DPI 未感知进程视角） |

说明：采集脚本以 PowerShell 运行，该进程未声明 DPI 感知，`Screen.Bounds` 与 `GetDpiForMonitor` 返回的是虚拟化后的逻辑值（1536×864、96 DPI）。1536×864 × 1.25 = 1920×1080，与该机型屏幕一致。Repeat 应用在启动时声明 Per-Monitor V2 DPI 感知，钩子坐标按物理像素处理；核对时应使用应用读取的桌面几何，不能把本脚本的逻辑坐标直接送入注入接口。验证结果与剩余环境边界统一见[实施计划](../implementation-plan.md)。

当前环境为单屏、无负坐标、无多屏混合 DPI；多屏与负坐标处理已在几何模型中预留（`SM_XVIRTUALSCREEN` 归一化），但本机无法实测，标注为未验证。
