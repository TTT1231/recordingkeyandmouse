# Repeat

Repeat 是一款桌面键鼠录制、编辑与回放工具。录下一段操作，调整需要修改的动作，再按原有节奏重复执行，让日常重复操作更省事。

## 功能

- **连续录制**：同步记录 Windows 桌面画面、键盘、鼠标及操作之间的停顿，保留输入顺序和移动轨迹。
- **动作编辑**：调整鼠标位置、点击方式、滚动量和键盘输入，插入文本或等待，支持撤销与重做。
- **时间线预览**：随时间查看当时的真实桌面画面与键鼠反馈；旧任务仍可导入参考图辅助查看与选点。
- **重复执行**：支持单次、自定义次数和无限循环，通过按钮或全局快捷键停止。
- **任务管理**：分别保存多项录制，修改自动保存在本机。
- **独立演示**：通过内置练习熟悉查看与编辑操作，练习数据与个人任务隔离。

## 使用

1. 新建或选择任务，点击「开始录制」或按 F8。主窗口收起，在 3 秒准备倒计时内切换到目标应用；准备期间可点击悬浮停止按钮或按 F8 / Esc 取消，原任务不变。
2. 倒计时结束后开始记录。悬浮条显示录制状态和时长，点击停止或按 F8 结束并返回预览；状态条与提示边框不进入录制画面。新录制成功保存后替换当前内容，放弃本次录制保留原任务。
3. 单击录制内容定位预览，右键菜单可编辑、插入等待、插入文本或删除；选中动作后也可按 F2 编辑。
4. 「预览」只在应用内播放；「执行到系统」会实际操作桌面。执行前有 3 秒准备倒计时，可随时点击停止或按 F9 结束。

F8 / F9 可在「帮助 → 快捷键设置」中调整。首次使用可从「帮助 → 使用演示」进入练习空间。

录像保存在本机，预览展示录制时的历史画面；修改动作不会重新生成目标应用的画面。桌面画面录制要求 Windows 10 2004 或更新版本及系统媒体组件，目前不录制音频。

## 从源码运行（Windows）

开发环境：

- Node ≥ 24、pnpm 12
- Rust stable
- MSVC C++ 构建工具、Windows SDK、WebView2 运行时

```powershell
pnpm install
pnpm tauri dev
```

`pnpm dev` 仅启动前端开发服务，系统录放需使用 Tauri 桌面应用。

| 命令 | 用途 |
| --- | --- |
| `pnpm tauri build` | 构建桌面发布包 |
| `pnpm lint` / `pnpm typecheck` / `pnpm test` | 前端静态检查与单元测试 |
| `pnpm format` | 格式化 |

Rust 检查与 Git Bash 配置见 [AGENTS.md](AGENTS.md#验证改动)。
